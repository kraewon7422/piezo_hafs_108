압전 타일 5×4 배선과 아두이노 연결

디스크 20개 배치·배선 → 측정 박스(정류·보호·분압) → 아두이노 우노 핀 → 밟힘 보호 구조 → 급식실 앞 설치·측정 코드

정정·주의 (저장소 검토)

  • Ropt = 1/(2πfC) 근거와 "디스크 1개 Ropt ≈ 5.3 MΩ(이전 차시)"는 철회된 값이다. 사인파 식을 펄스 입력에 쓴 것이다. 최적 부하는 실측으로 정한다.
  • "예상 평균 발전량 약 0.19 mW"는 3월의 근거 없는 추정이다(걸음당 5 mJ를 가정). 중간보고서의 전면 포설 추정은 약 1.7 mW이고, 둘 다 측정값이 아니다.
  • 브리지 손실: DB107 하나에 약 0.7~1 V(작은 전류에서 다이오드 2개)가 떨어진다. 손으로 누르면(1.1~1.3 V) 거의 0으로 읽힐 수 있다. 회로 고장이 아니므로 발로 밟아 보정한다.
  • A0 값 ≠ 개방전압: 1.1 MΩ × 디스크 약 20 nF = 시정수 약 22 ms로, 누름(약 0.1 s)보다 짧다. 읽은 피크는 누르는 속도에 따라 개방전압의 약 0.2~0.8배다.
  • 분해능: 1/11 분압이므로 ADC 1칸 = 행 전압 약 53.7 mV, 최대 약 55 V.
  • 보호 부품: BAT85가 없으면 5.1 V 제너보다 1N4148 2개(A핀→5V, GND→A핀)가 낫다. 제너는 1 V에서도 최대 10 µA 새고, 무릎이 완만해 위쪽 값이 눌린다.
  • E모드: 24 V 제너(1N4749A)는 18 V에서 최대 5 µA 새서 분압기보다 많이 소모할 수 있다. 한 걸음에 47 µF가 약 +13 mV(30 V, 20 nF 기준)만 오르므로 24 V까지 수천 걸음이 필요하다.
  • 9 V 전지 시험값 0.82 V는 ROW+ 단자에 직접 넣었을 때 값이다. 브리지를 거치면 약 0.72 V가 정상이다.
  • 이 설계와 코드(arduino/v3_array5x4/)는 아직 실제 부품으로 시험하지 않았다.

사진과 같은 점, 바꾸는 점

그대로 두는 것판 위에 디스크 5열 × 4행 배치, 디스크마다 선 2가닥(은색 가운데 1 · 황동 테두리 1), 전기테이프로 고정, 선 묶음을 한쪽 끝으로 모아 빼기.
바꾸는 것① 디스크마다 브리지 정류기(BR) 1개를 붙인 뒤 행별로 병렬 연결. ② 디스크를 직접 밟지 않게 상판·범퍼·스토퍼 구조로 감싸기. ③ 아두이노는 타일 밖 박스에 넣고 보호 회로를 거쳐 연결.

정류기를 붙이는 이유: 디스크끼리 바로 묶으면 밟힌 디스크에서 나온 전하가 안 밟힌 디스크(각각 커패시터, 약 15 nF로 가정)로 흘러가 전압이 나뉘어 줄어듭니다. 또 순간마다 디스크의 휘는 방향이 달라 +와 −가 서로 상쇄됩니다. 디스크마다 정류하면 디스크 쪽으로 전류가 거꾸로 흐를 수 없고 극성도 신경 쓸 필요가 없습니다. 지난번 A0 직결 측정에서 생긴 음의 반주기 잘림(샘플의 29%가 0)도 전파 정류로 함께 해결됩니다.

1. 타일 안 배선: 5×4 배열

휴대폰에서는 그림을 옆으로 밀어서 보세요.

  1. 디스크 → BR (납땜): 디스크의 선 2가닥을 BR의 ~ 다리 2개에 하나씩 납땜하고 수축튜브를 씌웁니다. 극성은 상관없습니다. BR 다리는 가늘어서 와고에 꽂으면 밟을 때 진동으로 빠집니다.
  2. BR +, − 다리: 각각 전선 10~20 cm를 납땜해 길게 뺍니다(+는 빨강, −는 검정).
  3. BR + → 그 행의 빨간 버스(ROWn+), BR − → 검정 GND 버스. BR 몸통에 +, − 가 찍혀 있습니다(DB107은 모서리가 깎인 쪽이 +).
  4. 한 행의 BR 5개는 + 끼리, − 끼리 병렬로 연결합니다. 이때 와고를 씁니다. 한쪽에 선이 6가닥(BR 5 + 출력 1) 모이므로, 5구 와고에 BR 4개 + 연결선을 꽂고 3구 와고에 연결선 + BR 1개 + 출력선을 꽂습니다. 행마다 + 쪽 1세트, − 쪽 1세트가 필요합니다. 출력은 ROW1+ ~ ROW4+ 4가닥과 공통 GND입니다.
  5. 모든 행의 GND 버스는 타일 오른쪽 끝에서 하나로 합칩니다.
  6. 행을 따로 측정하는 이유: 사람이 1행 → 4행 순서로 지나가므로, 행별 신호가 언제 들어왔는지로 발걸음 수와 방향, 디스크 위치별 출력 차이를 함께 얻을 수 있습니다.
정정: 아래 이유는 철회된 계산이다. 1/(2πfC)는 사인파 식이라 한 번 누르는 펄스에 맞지 않고, 디스크마다 브리지가 있어 회로가 보는 원천은 디스크 1개(약 20 nF)다. 1.1 MΩ는 "보호·분압에 알맞은 값" 정도로만 본다. 1.1 MΩ × 20 nF ≈ 22 ms라서 A핀 값은 개방전압이 아니다. 개방전압에 가깝게 읽으려면 10 MΩ / 1 MΩ(시정수 약 220 ms)를 쓰고 10 nF는 그대로 둔다.
(원문) 부하 1.1 MΩ로 정한 이유 (추정): 한 행에서 디스크 5개가 병렬이면 C ≈ 5 × 15 nF = 75 nF입니다. 걸음 주파수 2 Hz에서 R_opt = 1/(2πfC) ≈ 1.06 MΩ이므로, R1+R2 = 1.1 MΩ가 행 하나의 최적 부하와 거의 같습니다. C_p는 아직 가정값이니 실측하면 R1을 맞춰 바꾸세요.
간단하게 하고 싶을 때: BR을 행마다 1개(총 4개)만 쓰는 방법도 있습니다. 이때는 행 안에서 디스크 5개의 황동끼리, 은색끼리 같은 선에 묶어야 합니다. 대신 한 발에 1~2개만 눌리면 전압이 나머지 디스크로 나뉘어 1/3~1/5 정도로 줄어드니, 이 방식을 쓰면 보고서에 한계로 적으세요.

2. 측정 박스 회로 (아두이노 앞 보호·분압)

①은 같은 회로를 4개 만듭니다(소형 브레드보드에 들어갑니다). ②는 E모드용이라 처음에는 빼도 됩니다.

BAT85 대신 이미 산 5.1 V 제너(1N4733A)를 쓸 때: D1·D2를 빼고 제너를 R2와 나란히 꽂습니다(띠는 신호선 쪽, 반대쪽은 GND). 행마다 1개씩 총 4개가 필요합니다. 아두이노 보호는 되지만, 제너는 5.1 V 아래에서도 전류가 조금 새서(데이터시트 최대 10 µA, 1 V 기준) 측정값이 실제보다 낮게 찍힐 수 있습니다. 이 방식을 쓰면 보고서 한계에 적고, 9 V 전지 시험값(0.82 V)과 비교해 오차를 확인하세요.

부품마다 하는 일

  • R1 / R2 분압 (1/11): 행 전압 55 V가 A핀에서 5 V가 됩니다. 저항이 크기 때문에 넘치더라도 흐르는 전류는 수십 µA 수준입니다.
  • D1·D2 BAT85 (쇼트키): A핀 전압을 −0.3 V ~ 5.3 V 안으로 묶어 둡니다. D1의 띠는 5V 쪽, D2의 띠는 신호선 쪽으로 향하게 꽂습니다. 5V 핀은 전원을 공급하는 용도가 아니라 이 다이오드의 기준으로만 씁니다.
  • 10 nF: 우노 ADC는 입력 임피던스가 10 kΩ 이하인 신호를 전제로 만들어졌습니다. 10 nF가 순간 전하를 공급하므로 채널끼리 섞이는 현상(crosstalk)이 줄고, 3.3 kHz 링잉도 걸러집니다. 시간상수가 약 0.9 ms라서 수십 ms 길이의 발걸음 펄스 모양은 유지됩니다.
  • ZD 24 V: 저장 커패시터가 24 V를 넘지 않게 막아 커패시터(63 V)와 분압 회로를 보호합니다. 띠(캐소드)는 + 쪽으로 향하게 꽂습니다.
  • R3 / R4 = 10 MΩ / 2.2 MΩ: 24 V일 때 A4가 4.3 V가 됩니다. 1 MΩ급을 쓰면 20 V에서 분압 저항 혼자 약 0.33 mW를 소모해, 예상 평균 발전량(약 0.19 mW)보다 커집니다. (정정: 0.19 mW는 3월의 근거 없는 초기 추정이다. 중간보고서의 급식실 전면 포설 추정은 약 1.7 mW이며, 둘 다 측정값이 아니다. 어느 쪽이든 1 MΩ급 분압은 낭비가 크다는 결론은 같다.) 그래서 10 MΩ급으로 정했습니다.
  • 방전 버튼 + 100 Ω: 측정을 시작하기 전에 눌러 커패시터를 0 V로 비웁니다.

4. 타일 → 박스 연결선: LAN 케이블 하나로

Cat5e 랜선(8심, 2~3 m)을 쓰면 4쌍이 딱 맞습니다. 쌍마다 신호선과 GND를 꼬아 두면 잡음이 줄어듭니다.

쌍색선흰색 줄무늬 선
1주황 = ROW1+흰주황 = GND
2초록 = ROW2+흰초록 = GND
3파랑 = ROW3+흰파랑 = GND
4갈색 = ROW4+흰갈색 = GND

흰색 줄무늬 선 4가닥은 양쪽 끝에서 각각 하나로 묶습니다. 케이블이 박스로 들어가는 구멍에는 고무 그로밋이나 케이블 글랜드를 끼우고, 박스 안에서는 케이블 타이로 고정합니다. 그러면 케이블을 잡아당겨도 납땜 부위에 힘이 걸리지 않습니다.

5. 밟힘 보호

타일 단면: 디스크는 직접 밟히지 않게

사진처럼 천이나 판 위에 디스크를 붙이고 그대로 밟으면 세라믹이 금방 깨지고, 납땜 부위도 떨어집니다.

  • 힘의 경로: 발 → 매트 → 상판 → 고무 반구 → 디스크 가운데 → 디스크가 와셔 구멍 쪽으로 휨. 테두리만 받쳐지고 가운데만 눌리므로, 압전 디스크가 가장 잘 발전하는 굽힘 모드로 동작합니다. 와셔가 받침 링 역할을 하므로 아크릴에 구멍을 뚫을 필요가 없습니다.
  • 와셔 크기: 황동 테두리만 받치고 세라믹은 떠 있어야 합니다. 27 mm 디스크는 안지름 21~22 mm, 바깥지름 30 mm 이상(M20 와셔급), 35 mm 디스크는 안지름 26~28 mm가 맞습니다. 작은 와셔(안지름 10 mm)는 세라믹 가운데를 받쳐서 디스크가 거의 휘지 않습니다.
  • 스토퍼: M4 볼트를 두 판에 관통시키고 너트로 높이를 맞춰, 상판이 0.3~0.5 mm 넘게 내려가지 않게 받칩니다. 체중이 많이 실려도 나머지 하중은 스토퍼가 받습니다. 이 간극은 추정값이니 한 개로 시험하면서 깨지지 않는 값으로 조정하세요.
  • 배선: 전선은 하판 위 디스크 사이로 지나가게 하고 테이프로 고정합니다. 고무 반구와 스토퍼 자리는 피해야 상판에 눌려 끊어지지 않습니다. 납땜 부위는 핫글루로 덮습니다.
  • BR·와고 높이: BR(약 8 mm)과 와고(약 8 mm)는 와셔+디스크+반구보다 높을 수 있습니다. 판 사이 간격보다 높으면 타일 바깥 가장자리 쪽에 두고, 상판이 덮지 않는 테두리 밖에 모으세요.

6. 급식실 앞 배치

  • 타일은 입구 정면의 동선 위에 놓고, 행이 걷는 방향과 직각이 되게 둡니다(1행이 입구에서 먼 쪽).
  • 타일 둘레의 경사 테두리와 주의 표지로 걸려 넘어지는 것을 막습니다. 설치 전에 담당 선생님(생물정보학 ET)과 학교의 허가를 받으세요.
  • 사람 수 검증: 측정하는 동안 한 명이 수동 계수기로 지나간 사람 수를 세어 두면, STEP 수와 비교해 센서 정확도를 낼 수 있습니다.

8. 측정 코드

아두이노 (우노에 업로드)

// 유리프 압전 타일 5x4 측정 코드 — Arduino Uno
// A0~A3 : ROW1~4 측정 노드 (R1 1MΩ / R2 100kΩ 분압)   → S모드
// A4    : 저장 커패시터 노드 (R3 10MΩ / R4 2.2MΩ 분압) → E모드
// 시리얼 115200. 'r' 를 보내면 RAW 파형 출력 켜기/끄기

const float VREF = 5.00;                  // 멀티미터로 잰 5V 핀 실제 전압으로 바꿀 것
const float R1 = 1000000.0, R2 = 100000.0;  // 실측 저항값으로 바꿀 것
const float R3 = 10000000.0, R4 = 2200000.0;
const float C_STORE = 47e-6;              // 47 µF

const int ROW_PIN[4] = {A0, A1, A2, A3};
const int CAP_PIN = A4;
const int LED_PIN = 8;                    // 발걸음 표시용 (USB 전원 — 발전 증거 아님)

const float TH_ON  = 1.0;                 // 발걸음 시작: 어느 행이든 1.0 V 초과
const float TH_OFF = 0.3;                 // 발걸음 끝: 모든 행 0.3 V 미만이 50 ms 지속
const unsigned long SAMPLE_US = 1000;     // 1 kHz (5채널 순차 읽기)
const unsigned long NONE = 0xFFFFFFFF;

float kRow, kCap, dt;
bool inStep = false, rawMode = false;
unsigned long lastSample, lastCapPrint, stepStart, quietSince, stepCount = 0;
float peakV[4], energyJ[4];
unsigned long firstHit[4];
byte rawDiv = 0;

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  kRow = VREF / 1023.0 * (R1 + R2) / R2;   // ADC 값 → 행 버스 실제 전압
  kCap = VREF / 1023.0 * (R3 + R4) / R4;   // ADC 값 → 커패시터 실제 전압
  dt = SAMPLE_US * 1e-6;
  Serial.println(F("# STEP,번호,시작ms,지속ms,피크1~4(V),에너지1~4(uJ),첫접촉1~4(ms,-1=없음)"));
  Serial.println(F("# CAP,ms,Vcap(V),E=1/2CV^2(uJ)"));
  lastSample = micros();
}

void endStep(unsigned long ms) {
  stepCount++;
  Serial.print(F("STEP,")); Serial.print(stepCount); Serial.print(',');
  Serial.print(stepStart); Serial.print(','); Serial.print(ms - stepStart);
  for (int i = 0; i < 4; i++) { Serial.print(','); Serial.print(peakV[i], 2); }
  for (int i = 0; i < 4; i++) { Serial.print(','); Serial.print(energyJ[i] * 1e6, 3); }
  for (int i = 0; i < 4; i++) {
    Serial.print(',');
    if (firstHit[i] == NONE) Serial.print(-1); else Serial.print(firstHit[i]);
  }
  Serial.println();
  inStep = false;
  digitalWrite(LED_PIN, LOW);
}

void loop() {
  if (Serial.available()) { if (Serial.read() == 'r') rawMode = !rawMode; }

  unsigned long now = micros();
  if (now - lastSample < SAMPLE_US) return;
  lastSample += SAMPLE_US;
  if (now - lastSample > 10 * SAMPLE_US) lastSample = now;   // 밀리면 재동기화

  unsigned long ms = millis();
  float v[4], vmax = 0;
  for (int i = 0; i < 4; i++) {
    v[i] = analogRead(ROW_PIN[i]) * kRow;
    if (v[i] > vmax) vmax = v[i];
  }

  if (!inStep && vmax > TH_ON) {                 // 발걸음 시작
    inStep = true; stepStart = ms; quietSince = 0;
    for (int i = 0; i < 4; i++) { peakV[i] = 0; energyJ[i] = 0; firstHit[i] = NONE; }
    digitalWrite(LED_PIN, HIGH);
  }

  if (inStep) {
    for (int i = 0; i < 4; i++) {
      if (v[i] > peakV[i]) peakV[i] = v[i];
      energyJ[i] += v[i] * v[i] / (R1 + R2) * dt;   // 부하(R1+R2)에 전달된 에너지
      if (firstHit[i] == NONE && v[i] > TH_ON) firstHit[i] = ms - stepStart;
    }
    if (vmax < TH_OFF) {
      if (quietSince == 0) quietSince = ms;
      else if (ms - quietSince > 50) endStep(ms);
    } else quietSince = 0;
    if (inStep && ms - stepStart > 3000) endStep(ms);   // 3초 넘게 서 있으면 끊기
  }

  if (rawMode && ++rawDiv >= 4) {                // 250 Hz 파형 출력
    rawDiv = 0;
    Serial.print(F("RAW,")); Serial.print(ms);
    for (int i = 0; i < 4; i++) { Serial.print(','); Serial.print(v[i], 2); }
    Serial.println();
  }

  if (ms - lastCapPrint >= 1000) {               // 1초마다 저장 커패시터
    lastCapPrint = ms;
    float vc = analogRead(CAP_PIN) * kCap;
    Serial.print(F("CAP,")); Serial.print(ms); Serial.print(',');
    Serial.print(vc, 3); Serial.print(',');
    Serial.println(0.5 * C_STORE * vc * vc * 1e6, 2);
  }
}

출력 예: STEP,12,53021,148,8.41,6.02,0.00,0.00,3.120,1.884,0.000,0.000,0,37,-1,-1 → 12번째 발걸음이고 148 ms 동안 지속, 1행이 먼저 눌리고 37 ms 뒤 2행이 눌렸다는 뜻입니다.

노트북에서 CSV로 저장 (Python)

# pip install pyserial  /  python logger.py COM3   (맥: /dev/cu.usbmodemXXXX)
import sys, serial, datetime

port = sys.argv[1] if len(sys.argv) > 1 else "COM3"
name = datetime.datetime.now().strftime("piezo_%Y%m%d_%H%M%S.csv")
with serial.Serial(port, 115200, timeout=1) as ser, open(name, "w", encoding="utf-8") as f:
    print("저장 중:", name, "(끝내려면 Ctrl+C)")
    try:
        while True:
            line = ser.readline().decode("utf-8", "ignore").strip()
            if not line:
                continue
            stamp = datetime.datetime.now().isoformat(timespec="milliseconds")
            f.write(stamp + "," + line + "\n")
            f.flush()
            if line.startswith("STEP"):
                print(line)
    except KeyboardInterrupt:
        print("종료")

9. 시험 순서

  1. 보정: 멀티미터로 우노 5V 핀의 실제 전압과 R1·R2·R3·R4의 실제 저항값을 재서 코드 맨 위 숫자를 바꿉니다.
  2. 보호 회로 확인: 9 V 전지를 ROW1 입력에 연결했을 때 A0에서 약 0.82 V(= 9 × 100/1100)가 나오는지 확인합니다. 아두이노를 꽂기 전에 멀티미터로 먼저 확인하세요.
  3. 책상 시험: 디스크 1개 + BR 1개를 연결하고 손가락으로 눌러 STEP 줄이 찍히는지 봅니다. (주의: 손가락 누름은 1.1~1.3 V인데 브리지가 약 0.7~1 V를 먹으므로 거의 0으로 읽힐 수 있다. 고장이 아니다. 발로 밟아 확인한다.) 'r'을 보내 RAW 파형도 확인합니다.
  4. 디스크 1개 하중 시험: 와셔·디스크·고무 반구·상판 조각으로 하나만 만들어 체중을 천천히 실어 보고, 스토퍼 너트 높이를 조정합니다.
  5. 타일 완성 후 실내 시험: 여러 번 지나가며 행 순서와 에너지가 일정한지 확인합니다.
  6. 저장 커패시터 자체 방전 측정 (E모드 전 필수): 9 V 전지로 47 µF를 충전한 뒤 전지를 떼고, 밟지 않은 상태로 10분간 CAP 값을 기록합니다. 전해 커패시터의 누설 전류와 R3+R4의 누설이 합쳐진 감소 곡선이 나오며, E모드 결과를 이 값으로 보정합니다.
  7. 현장 측정: 방전 버튼을 누르고 S모드로 측정하면서 사람 수를 셉니다. 그다음 E모드로 같은 시간 동안 측정합니다.

10. 보고서에 적을 한계

  • BR 1개에서 다이오드 2개를 지나므로 약 1.4~2 V가 손실됩니다. 수십 V 펄스에서는 작지만, 약하게 밟았을 때는 비중이 커집니다.
  • S모드 에너지는 1.1 MΩ 부하에 전달된 값입니다. E모드 에너지는 커패시터 충전 효율과 누설에 따라 달라지므로, 두 값이 다른 것이 정상입니다.
  • 디스크의 C_p(15 nF)와 R_opt 계산은 아직 가정값입니다. 실측하면 결과에 반영하세요.
  • 우노 ADC 1 kHz로는 3.3 kHz 링잉을 볼 수 없습니다. 발걸음 단위의 에너지와 계수용 측정이며, 링잉 파형은 기존 FFT 측정 결과를 인용하세요.
