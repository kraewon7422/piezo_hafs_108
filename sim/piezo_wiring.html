스타터 키트 배선도

키트에 1 MΩ 저항·다이오드·커패시터가 없습니다. 있는 부품만으로 회로 A와 B는 그대로 할 수 있고, 회로 C는 부품 두 개를 구해야 합니다. 아래는 실제로 꽂을 자리까지 적은 배선표입니다.

00키트 점검 결과

부품 목록 사진과 실험에 필요한 부품을 하나씩 대조한 결과입니다.

뜻밖의 좋은 소식 바이어스가 1 MΩ에서 50 kΩ으로 내려가면서 ADC 정확도 문제가 상당 부분 사라졌습니다. 아두이노 ADC는 신호원 임피던스 10 kΩ 이하를 권장하는데, 원래 계획(실효 500 kΩ)은 그 한참 위였습니다. 이제 실효 부하 최댓값이 25 kΩ이라 훨씬 안전합니다. 대신 MΩ대 보행 조건은 여전히 못 잽니다 — 그건 보고서에 한계로 그대로 남습니다.
그래도 꼭짓점은 잡힙니다 공진(3,332 Hz)에서 이론적 최적 부하는 1/(2πfC) ≈ 3.2 kΩ입니다(Cp=15 nF 가정). 가변저항 0~10 kΩ 범위의 한가운데라 P–R 곡선의 꼭짓점을 실제로 찾을 수 있습니다. 오늘 목표 세 개 중 Ropt는 키트만으로 달성 가능합니다.

01큰 저항은 직렬로 만든다

10 kΩ 저항이 10개 있으니, 옆 세로줄로 한 칸씩 건너뛰며 이어 꽂으면 원하는 값이 됩니다.

만들 값조합쓰는 곳오차
50 kΩ10kΩ ×5 직렬회로 A 바이어스 (양쪽에 하나씩)약 ±2%
100 kΩ10kΩ ×10 직렬회로 B 기준저항약 ±1.6%
2.2 kΩ1k + 1k + 220부하 스윕 중간점약 ±3%
3.3 kΩ1k ×3 + 330예상 꼭짓점 부근약 ±2.5%

저항 여러 개를 직렬로 이으면 각각의 ±5% 오차가 서로 상쇄되어 체인 전체 오차는 절반 이하로 줄어듭니다. 멀티미터가 없어도 이 정도면 쓸 만합니다.

03멀티미터 없이 가변저항 값 읽기

가변저항에는 눈금이 없습니다. 아두이노를 임시 저항계로 써서 지금 몇 옴인지 알아냅니다.

  1. pot_measure.ino를 올리고 위 그림대로 꽂습니다.
  2. 손잡이를 원하는 위치로 돌리고, 시리얼에 찍힌 R_ohm을 노트에 적습니다.
  3. 손잡이를 건드리지 말고 5V 점퍼만 뽑습니다.
  4. 가운데 핀을 7번 줄(노드)로 옮깁니다. 오른쪽 핀은 GND 레일에 그대로 둡니다.
  5. 회로 A 스케치를 다시 올리고 L 명령으로 적어둔 값을 기록합니다.

가변저항의 공칭 10 kΩ 자체가 ±20% 정도 틀릴 수 있습니다. 고정저항(±5%)으로 잡은 점들이 더 믿을 만하니, 가변저항은 곡선의 모양을 채우는 용도로 쓰고 결론은 고정저항 점들로 내리세요.

05회로 C — 오늘은 못 합니다

다이오드와 커패시터가 키트에 없습니다. 대신 데이터로 상한값을 계산하는 길이 있습니다.

대체가 안 되는 이유 LED도 다이오드지만 순방향 강하가 약 1.8 V라, 압전 출력 1.1 V로는 아예 도통하지 않습니다. 부저·릴레이·RTC 모듈에 부품이 붙어 있어도 납땜되어 있어 꺼내 쓸 수 없습니다. 정류·축전은 부품 없이는 물리적으로 불가능합니다.

구할 부품 (합쳐서 500원 안팎)

  • 다이오드 — 1N4148 또는 1N5819(쇼트키). 쇼트키가 손실이 절반 이하라 훨씬 유리합니다.
  • 세라믹 커패시터 — 103(10 nF) 또는 104(100 nF). 전해 100 µF는 쓰면 안 됩니다.
  • 과학실이나 기술실 부품함에 거의 항상 있습니다. 먼저 선생님께 여쭤보세요.
부품 없이 오늘 할 수 있는 것 회로 A의 파형에서 양(+) 반주기 구간만 골라 적분하면, 손실이 전혀 없는 이상적 반파 정류로 회수 가능한 에너지의 상한값이 나옵니다. 나중에 다이오드를 구해 실제로 측정한 값과 비교하면 그 차이가 곧 정류 손실입니다. 오늘은 상한값만 계산해 두고, 보고서에는 "정류 손실 측정은 부품 확보 후 다음 차시"로 적으면 됩니다.

06코드에서 바꾼 값

보낸 스케치 파일에는 이미 반영되어 있습니다. 직접 고칠 경우를 위해 적어 둡니다.

// piezo_A_load.ino
// 이전: const long  R_BIAS = 1000000L;   // 1 MΩ

// 이전: const float R_REF = 1000000.0;   // 1 MΩ
// 이전: uint16_t sampleUs = 100;
const float R_REF = 100000.0;     // 10kΩ x 10 직렬
uint16_t sampleUs = 20;           // tau가 1.5 ms로 짧아져 더 촘촘히 샘플링
