# 압전 발판 — 젯슨 오린 나노 버전 실행 가이드 (v1)

젯슨 + AI Starter Kit + 11인치 모니터에서 GUI를 띄우고, 키트 장치로 기능 4가지를 더합니다.
① 카메라 AI 사람 수 ② 발판·카메라·초음파 비교(화면 E) ③ 키트 LCD·숫자 표시기·LED ④ 상시 기록(10초마다 CSV)

## 1. 젯슨에 복사
`C:\dev\arduino` 폴더를 **통째로** 젯슨에 복사합니다(USB 메모리 등). 세 폴더가 같은 곳에 있어야 합니다.
```
arduino/piezo_main     아두이노 코드·logger·analyze (측정 폴더가 여기에 저장됨)
arduino/piezo_gui      화면 A~D (젯슨 버전이 그대로 가져다 씀)
arduino/piezo_jetson   이 폴더
```

## 2. 처음 한 번 설치
```
cd ~/arduino/piezo_jetson
chmod +x setup_jetson.sh run_jetson.sh
./setup_jetson.sh
```
한글 글꼴(fonts-noto-cjk), pyserial, pygame-ce, smbus2 를 설치하고 시리얼·I2C·GPIO 권한을 줍니다. **끝나면 로그아웃 후 다시 로그인(또는 재부팅)**.

확인:
- 아두이노 USB 연결 → `ls /dev/ttyUSB* /dev/ttyACM*` 에 하나가 보여야 함
- 키트 I2C 장치 → `i2cdetect -y -r 7` 에 27(LCD)·38(온습도)·70(숫자 표시기)이 보이면 정상 (안 보이면 `-r 1` 로)

## 3. 실행
```
./run_jetson.sh            메뉴: 1 실시간 / 2 최근 측정 재생
./run_jetson.sh --sim      카메라·초음파 없이 화면 시험 (가짜 숫자 — 발표 데이터로 쓰면 안 됨)
./run_jetson.sh --no-camera   카메라 끄고 실행 (프라이버시 문구도 사라짐)
./run_jetson.sh --windowed    창 모드 (기본은 전체화면)
```
| 키 | 기능 |
|---|---|
| Tab / Shift+Tab | 화면 A~E 전환 |
| R | 기록 초기화 (발판·카메라·초음파 숫자 모두 0) |
| F11 / F12 | 전체화면 전환 / 화면 PNG 저장 |
| Z | 잡음 기준선 다시 (실시간) |
| Esc | 종료 → 사람 수 요약 + analyze.py 자동 실행 |

## 4. 화면
- **A~D**: Windows 버전(piezo_gui)과 같음
- **E 사람 수 비교**: 카메라 모자이크 미리보기(노란 선을 넘으면 1명) + 발판·카메라·초음파 숫자 + 카메라 기준 비율 + 누적 그래프
- **카메라가 켜져 있으면 모든 화면 맨 위에** "개인 프라이버시를 위해 영상은 저장하지 않습니다!" 가 표시됩니다.

## 5. 프라이버시 (발표 때 설명할 것)
- 카메라 영상은 **어떤 파일로도 저장하지 않습니다**(코드에 영상·사진 저장 기능이 없음).
- 화면 미리보기도 **모자이크**(가로 24칸)로만 보여 줍니다. 더 흐리게: `jetson_hw.py` CONFIG 의 `privacy_pixel` 을 작게.
- 기록되는 것은 **사람 수(숫자)뿐**입니다 → 측정 폴더의 `jetson_counts.csv`
- 급식실 설치 전 **학교(담당 선생님) 허가**를 받으세요.

## 6. 카메라 사람 인식 방식
- 기본: OpenCV **HOG**(설치 필요 없음, CPU). 정면·옆모습 사람에 맞고, **위에서 내려다보는 각도에는 약함** → 카메라를 사람 옆모습이 보이게 두세요.
- 더 정확하게: **YOLO**(GPU). 젯슨용 PyTorch(NVIDIA 제공 JetPack 버전)를 설치한 뒤 `python3 -m pip install --user ultralytics`. 설치돼 있으면 자동으로 YOLO 를 씁니다(화면에 "YOLO (GPU)" 표시). 모델 파일 `yolov8n.pt` 는 이 폴더에 들어 있습니다.
- 세는 선: `line_axis`("y" 가로선 / "x" 세로선), `line_pos`(0~1) — 사람이 지나가는 방향에 맞춰 바꾸세요.

## 7. 키트 장치 설정 (`jetson_hw.py` 맨 위 CONFIG)
| 장치 | 설정 | 비고 |
|---|---|---|
| 초음파 | `us_trig=26, us_echo=16` | 키트 표기 TRIG-D26·ECHO-D16 을 **BCM 번호로 가정**. 응답 없으면 이 번호 확인 |
| LED | `led_pin=18` | 키트 표기 D18 → BCM 18 가정. 걸음(펄스)마다 깜박 |
| LCD | `lcd_addr=0x27` | `P4 C3 U4` / `E 32.1uJ 23C` 처럼 영문·숫자로 표시 (LCD 에 한글 글꼴 없음) |
| 숫자 표시기 | `seg_addr=0x70` | 발판 통과 인원. HT16K33 으로 가정 — 숫자 순서가 이상하면 `Seg4.POS` 수정 |
| 온습도 | `env_addr=0x38` | AHT20/AHT10. 5초마다 읽어 화면 E·CSV 에 기록 |
| 부저·RGB 매트릭스 | `kit_buzzer_beep()`, `kit_matrix_rows()` | 키트 전용 확장칩(STC8·RP2040)을 거쳐서 **키트 예제 코드가 필요**. 함수 자리만 있음 |

모든 장치는 없거나 실패해도 프로그램이 멈추지 않고 화면 E·터미널에 "없음"으로 표시됩니다.

## 8. 기록 파일
실시간 모드: `piezo_main/piezo_날짜_시각/` 에 logger.py 와 같은 파일 + **`jetson_counts.csv`**(10초마다: 시각, 발판·카메라·초음파 인원, 누적 에너지, 온도, 습도). 오래 켜 둘 때 저장 공간: 시간당 약 100 MB.

## 9. 검증용 (화면 PNG 저장)
```
python3 piezo_jetson_v1.py --replay ../piezo_main/piezo_20261121_192827/raw_serial.txt --snapshot 결과폴더 --until 30
```
화면 A~E 를 1920 폭·1280×800(11인치 예시)으로 저장합니다(가짜 카메라·초음파 숫자).
