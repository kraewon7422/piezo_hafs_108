# 압전 발판 실시간 GUI — 실행 가이드 (v1)

## 1. 실행
**`GUI_시작.bat` 더블클릭** → 번호 선택
- `1` 실시간 측정 — 아두이노(piezo_main.ino v3.1)를 USB로 연결한 상태
- `2` 재생 — `piezo_main` 폴더의 가장 최근 측정 데이터를 실제 속도로 재생 (아두이노 없이 시연)
- `raw_serial.txt` 파일을 bat 아이콘 위에 끌어다 놓으면 그 파일을 바로 재생

bat 파일이 UTF-8(`chcp 65001`, `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`)을 켜고, pyserial·pygame-ce가 없으면 설치합니다.

※ 실시간 측정 전 **Arduino IDE 시리얼 모니터와 logger.py(측정_시작.bat)를 꼭 닫으세요.** 포트는 한 프로그램만 열 수 있습니다.

명령줄로 직접 실행:
```
python piezo_gui_v1.py                                   실시간 (포트 자동)
python piezo_gui_v1.py --port COM5                        포트 지정
python piezo_gui_v1.py --replay ..\piezo_main\piezo_20261121_192827\raw_serial.txt --speed 2
```

## 2. 화면 (Tab으로 넘김, Shift+Tab은 뒤로)
| 화면 | 내용 |
|---|---|
| A 실시간 측정 | 발판 단면(발이 누르는 모습, 옆에서 본 1~4행), 행별 파형, 통과 인원·에너지 카드, 사람별 에너지, 누적 에너지 |
| B 설계 vs 측정 | 설계값(실제 발판 디스크 20개 기준)과 실측 비교(전하·전압·에너지·시간), 펄스별 Q–E 그래프, **에너지가 어디서 줄었는지 분석** |
| C 확장하면? | 실측 걸음당 에너지 × 외대부고 급식실 / 지하철역 → 하루 에너지를 IoT 전송·LED·스마트폰 충전 등으로 환산 |
| D 개선하면? | 지금 발판의 한계 + 개선 계산기(디스크 수·힘·소재·회로) |

## 3. 키
| 키 | 기능 |
|---|---|
| Tab / Shift+Tab | 화면 전환 |
| F11 | 전체화면 (발표용) · Esc로 창 모드 |
| F12 | 지금 화면을 PNG로 저장 (이 폴더에 `screenshot_날짜.png`) → 발표자료에 붙이기 |
| R | 기록 초기화 (시연 시작 전에) |
| Z | 잡음 기준선 다시 측정 (실시간) — 2초간 밟지 않기 |
| Space / 1·2·4·8 | 재생 일시정지 / 재생 속도 |
| ↑↓ ←→ | 화면 D 개선 계산기 조작 |
| Esc | 종료 (실시간이면 종료 후 analyze.py 요약이 자동 실행) |

## 4. 저장
실시간 모드는 `piezo_main\piezo_날짜_시각\` 폴더에 logger.py와 **똑같은 형식**으로 저장합니다(raw_serial.txt, pulses.csv 등).
그래서 나중에 `python analyze.py 폴더` 로 같은 분석을 할 수 있고, 이 폴더의 raw_serial.txt로 다시 재생할 수 있습니다.

## 5. 발표 전에 바꿀 값 (`piezo_gui_v1.py` 맨 위)
- `SCENARIOS` — 장소별 인원·끼니·통로 크기(`area_w`×`area_l` m). 발판 장수 = 통로 ÷ 발판 크기(`TILE_W_M`×`TILE_L_M`, 기본 0.5×0.4 m), 1명당 걸음 = 통로 길이 ÷ 보폭(`STRIDE_M` 0.65 m). 지금은 급식실 2×2.4 m(24장), 지하철역 10×4 m(200장) **가정값** — 실제 값으로 바꾸기
- `COMMERCIAL_J_PER_STEP` — 상용 발전 타일 걸음당 에너지 (가정 3 J)
- `TH_...` — 설계값: 실제 발판(조립 매뉴얼) 디스크 20개(4행 × 5열), 1개 20 nF + piezo_sim.py의 하중 760 N, d_eff 11 nC/N(가정). 멀티미터로 디스크 정전용량을 재면 `TH_CP_DISK`에 넣기
- `LEVERS` — 화면 D 개선 계산기의 배수 (예상치)

## 6. 검증용 (화면을 PNG로 저장)
```
python piezo_gui_v1.py --replay ..\piezo_main\piezo_20261121_192827\raw_serial.txt --snapshot 결과폴더 --until 26
```
26초 지점의 A~D 화면을 1920×1080, 1280×720 PNG로 저장합니다.

## 7. 값 읽는 법 (발표 때 주의)
- 측정 에너지는 **1.1 MΩ 측정 저항에 전달된 에너지**입니다(모아서 저장한 양이 아님).
- "통과 인원"은 펄스 간격 1초 이내를 1명으로 묶은 값입니다(analyze.py와 같은 규칙). 같은 사람이 계속 밟으면 1명으로 셉니다.
