전체 구조와 바뀐 점

디스크 20개는 디스크마다 브리지 정류기(BR)를 하나씩 붙이고, 행(가로 5개)마다 하나로 묶습니다. 그래서 아두이노에는 ROW1~4 네 가닥 + GND 한 가닥만 들어갑니다.

도착한 부품에 맞춰 지난번 계획에서 아래 세 가지를 바꿨습니다.

  • E모드(47 µF 저장) 빼기: 10 MΩ·2.2 MΩ 저항과 47 µF가 없어서, 펄스별 측정만 합니다. 에너지는 발걸음마다 코드가 계산합니다.
  • 보호: 1 MΩ + 1N4148 클램프: 1 MΩ 직렬 저항이 기본 보호이고, 1N4148 2개(행마다)로 입력을 약 −0.6~5.6 V 안에 한 번 더 묶습니다. 1N4148은 제너가 아니라 신호용 다이오드입니다(설계 검토).
  • 점퍼 모드 전환 없음: 회로가 행마다 저항 2개 + 다이오드 2개로 단순해졌습니다.
  • BR은 DB107S(표면실장형): 핀이 짧게 옆으로 꺾여 있어, 핀을 자르거나 구부리지 않고 핀 위에 전선을 얹어 납땜합니다(4단계).

③ 압전 디스크

  • 선이 달려 있으면: 빨강선은 세라믹 면, 검정선은 황동판에 붙어 있습니다. 이 회로는 BR이 극성을 정리하므로 색은 상관없습니다.
  • 선이 없으면: 4단계에서 직접 붙입니다(세라믹 위 1점, 황동 테두리 1점).
  • 멀티미터에 정전용량(F) 모드가 있으면 재 보세요. 약 15~25 nF면 정상입니다. 0이나 OL이면 선이 끊긴 것입니다.

④ 1N4148 다이오드 방향

  • 유리 몸통에 검은 띠가 있는 쪽 = 캐소드(K)입니다. 전류는 띠가 없는 쪽(A) → 띠 쪽(K)으로만 흐릅니다.
  • 멀티미터 다이오드 모드: 빨강 프로브를 띠 없는 쪽, 검정을 띠 쪽에 대면 약 0.5~0.7 V, 반대는 OL.
  • 1N4148은 제너 다이오드가 아닙니다. 5.1 V에서 멈추는 기능은 없고, 이 회로에서는 클램프(전압 묶기)로 씁니다.

표시하는 방법

  1. 하판의 보호 필름을 양면 모두 뗍니다. 필름 위에 표시하고 부품을 붙이면, 나중에 필름을 뗄 수 없거나 부품이 같이 떨어집니다.
  2. 하판 밑면(바닥에 닿는 면)에 유성펜으로 표시합니다. 아크릴이 투명해서 위에서 보입니다. 윗면은 깨끗하게 둬야 양면테이프가 잘 붙습니다.
  3. 표시할 것: 디스크 중심 20곳(+), BR 자리 20곳(□), 배선 통로 4줄(점선), 스토퍼 12곳(■). 스토퍼 x 값 = 판 끝 ↔ 1열 디스크 가장자리, BR 오른쪽 끝 ↔ 다음 디스크 가장자리, 5열 BR 오른쪽 끝 ↔ 판 끝의 가운데.
  4. 스토퍼 자리가 실제로 놓은 BR이나 선과 겹치면, 같은 행 안에서 좌우로 1 cm까지 옮겨도 됩니다.

3단계 디스크 붙이기

  1. 방향: 세라믹 면(은색)이 위, 황동 면이 아래입니다. 선이 붙은 면이 위를 봅니다.
  2. 세라믹 면 지름 재기: 자로 디스크 1개의 세라믹 면(은색 원) 지름을 잽니다. 보통 19~20 mm입니다. 받침 패드는 이 원 바깥, 디스크 가장자리(반지름 13.5 mm) 안쪽에만 있어야 합니다.
  3. 받침 패드 붙이기: 디스크 중심 표시에서 약 11.5 mm 떨어진 네 곳(대각선)에 붙입니다. 세라믹 면이 지름 20 mm보다 크면 그만큼 바깥으로 옮깁니다.
    1. 폼 양면테이프: 가로세로 2~3 mm 조각 4개, 두께 1 mm 이상(얇으면 2~3겹). 황동 테두리 폭이 약 3.5~4 mm라 더 크면 세라믹 면 밑으로 들어갑니다.
    2. 와셔가 있으면 패드 대신 1개: 안지름이 세라믹 면 지름보다 크고, 바깥지름이 27 mm 이상인 것만.
  4. 디스크 얹기: 디스크선이 BR 쪽(오른쪽)을 향하게 돌려서, 받침 패드 위에 황동 테두리만 닿게 눌러 붙입니다. 세라믹(은색) 부분은 아무것에도 닿지 않아야 합니다. 그래야 가운데가 아래로 휘면서 전압이 납니다.
  5. 누름 범폰 붙이기: 세라믹 면 정중앙에 붙입니다. 디스크선 납땜점 위는 피하세요. 56개 세트에서 같은 크기 20개를 고르고, 높이를 자로 재서 적어 둡니다(h, 10단계에서 씀).
점검 — 디스크를 옆에서 봤을 때 세라믹 밑에 틈이 보여야 합니다. 손가락으로 누름 범폰을 살짝 누르면 디스크가 조금 휘었다가 돌아와야 합니다.

4단계 납땜

디스크 하나에 납땜 4곳(디스크선 2 + BR 출력 2)이라 모두 80곳입니다. DB107S는 발이 작아서 BR을 판에 먼저 붙이고 전선을 얹어 납땜합니다. 먼저 디스크 1개만 완성해서 9단계 시험 ②까지 해 보고, 잘 되면 나머지 19개를 합니다.

그림 ①~④가 아래 1~6번 순서와 같습니다. 디스크 20개 모두 같은 방법입니다.

  1. BR 먼저 고정: DB107S를 표시한 자리에 글씨가 위로 보이게 놓고 양면테이프로 판에 붙입니다. 몸통이 움직이지 않아야 작은 핀에 납땜하기 쉽습니다.
  2. 발과 전선에 납 입히기(예비 납땜): 전선 피복을 3 mm만 벗기고 꼬아서 납을 살짝 입힙니다. BR의 각 핀에도 인두를 1초 대고 납을 조금 올립니다.
  3. 디스크선 → ~ 핀 2개: 납 입힌 전선 끝을 ~ 핀 위에 눕혀 얹고, 인두로 2~3초 눌러 두 납을 녹여 붙입니다. 두 디스크선은 아무 ~에나 붙여도 됩니다.
  4. + 핀 → 빨강선, − 핀 → 검정선: 같은 방법으로 붙입니다. 길이는 '전선 예산' 표(그 열 기준)대로 자르고, 끝에 행-열 번호 테이프(예: 2-3)를 붙입니다.
  5. 합선 확인: 핀 사이가 좁으니 납이 옆 핀까지 번지지 않았는지 눈으로 보고, 붙었으면 인두로 녹여 떼어 냅니다.
  6. 절연·고정: 지름 약 10 mm 열수축 튜브를 BR 몸통째 씌워 수축하거나(납땜 전에 전선에 미리 끼워 둠), 전기테이프로 BR과 핀 4개를 덮습니다. 전선은 BR에서 2 cm 떨어진 곳을 테이프로 판에 붙여, 당겨도 힘이 핀에 가지 않게 합니다.
디스크에 직접 선을 붙여야 할 때 — 세라믹(은색) 위 납땜은 3초 안에 끝냅니다. 오래 가열하면 은 전극이 녹아 벗겨지고 압전 성질이 약해집니다. 황동은 넓어서 열이 잘 빠지므로 납을 조금 더 녹이세요.
점검 (납땜한 BR마다) — 멀티미터 다이오드 모드로 검정 프로브를 빨강선(+), 빨강 프로브를 검정선(−)에 대면 약 1.0~1.4 V가 떠야 합니다. 반대로 대면 OL. 0 V 근처면 합선입니다.

  3. 반응 없는 디스크는 표에 적고, 그 디스크의 납땜·와고를 다시 봅니다.
기록 팁 — 디스크 20개를 같은 손가락 힘으로 눌렀을 때의 피크값을 표로 남기면, 디스크마다 출력이 얼마나 다른지 보여 주는 자료가 됩니다(최종보고서 근거).

10단계 상판·스토퍼

스토퍼 높이 정하기

상판은 누름 범폰 위에 얹힙니다. 누름 범폰 꼭대기 높이 H보다 스토퍼를 0.3~0.5 mm 낮게 하면, 그만큼만 눌리고 나머지 체중은 스토퍼가 받습니다.

항목기호예시재는 법
받침 두께t1.0 mm와셔·폼 테이프 두께
디스크 두께d0.5 mm황동 + 세라믹
누름 범폰 높이h3.0 mm3단계에서 잰 값
누름 범폰 꼭대기H = t + d + h4.5 mm자를 하판에 세워 직접 재기
스토퍼 높이H − 0.44.1 mm0.3~0.5 mm 낮게
  • BR 높이 확인: DB107S(약 2.5~3 mm) + 테이프 두께가 스토퍼보다 낮아야 상판에 눌리지 않습니다. 높으면 받침을 한 겹 더 붙여 H를 올리세요.
  • M4 너트로 할 때: 너트 1개(높이 3.2 mm)에 얇은 조각을 더해 H − 0.4 mm를 맞추고, 양면테이프로 하판에 붙입니다. 볼트는 필요 없습니다(볼트 머리 + 나사 길이가 H보다 길어짐).
  • 동전·아크릴 조각으로 할 때: 겹친 뒤 자로 높이를 재고, 양면테이프 층으로 미세 조절합니다.

상판 덮기

  1. 하판과 상판의 보호 필름을 떼고, 상판을 누름 범폰 위에 맞춰 얹습니다.
  2. 상판 윗면에 미끄럼 방지 테이프를 붙입니다(아크릴은 밟으면 미끄럽습니다).
  3. 옆면 고정: 두 판의 옆면을 전기테이프로 둘러 어긋나지 않게 합니다. 이때 테이프를 팽팽하게 당기지 마세요. 상판이 미리 눌려 누름 범폰을 계속 누르게 됩니다.
  4. 전선이 나가는 오른쪽 변은 선이 판 사이에 끼지 않게 테이프로 정리합니다.

11단계 체중 시험·설치

  1. 천천히 체중 싣기: 한 발을 판 가운데 올리고 천천히 체중을 싣습니다. 시리얼 모니터(또는 로거 화면)에 펄스가 찍히고, 판에서 "딱" 소리나 금 가는 느낌이 없어야 합니다.
  2. 걸어서 지나가기: 1행 → 4행 방향으로 10번 지나간 뒤 로거를 끄고 analyze.py를 돌립니다. "통과 10회", "방향: 1행→4행 10회"에 가깝게 나오는지 확인합니다.
  3. 스토퍼 조정: 전압이 너무 작으면 스토퍼를 0.1~0.2 mm 높입니다(눌림 양 증가). 디스크가 하나라도 깨지면 스토퍼를 낮춥니다.
  4. 기준선: 로거를 켤 때(우노가 재시작됨) 2초 동안 아무도 타일을 밟지 않게 합니다. 중간에 다시 재려면 시리얼로 z를 보냅니다.
  5. 설치: 담당 선생님과 학교 허가 후 급식실 앞 동선에 놓습니다. 와고 쪽 변은 벽 쪽으로, 측정 박스(우노 + 브레드보드)는 통행로 밖에 둡니다.
  6. 데이터 기록: 노트북에서 logger.py로 저장하고, 같은 시간 동안 한 명이 지나간 사람 수를 셉니다. 끝나면 python analyze.py 폴더 --count 센인원 --people 하루인원.
우노 USB가 빠진 상태에서 판이 밟혀도 고장 나지 않습니다. 1 MΩ이 전류를 수십 µA 수준으로 막기 때문입니다.

// 유리프 압전 타일 측정 코드 v3 — Arduino Uno
// 회로: ROWn+ → 1MΩ → 측정점(A0~A3) → 100kΩ → GND, 1N4148 클램프(측정점↔5V, GND↔측정점)
// 시리얼 250000 baud (Arduino IDE 시리얼 모니터 오른쪽 아래도 250000으로)
//
// 출력 줄 종류 (맨 앞 글자로 구분, 쉼표 구분)
//   M  : 설정값 (시작할 때 1번)          M,버전,VREF,R1,R2,샘플주기us,TH_ON_V,TH_OFF_V
//   B  : 잡음 기준선 (시작 후 2초 측정)  B,ms,평균1~4(V),최대1~4(V)
//   R  : 원자료 (2 ms마다, ADC 값 0~1023)  R,ms,a0,a1,a2,a3
//   P  : 펄스 1개 요약 (디딜 때·뗄 때 각각 1줄) — 아래 P_HEADER 참고
//   S  : 상태 (10초마다)                 S,ms,펄스수,놓친샘플수,잡음최대1~4(V)
// 명령: r = 원자료(R) 켜기/끄기,  z = 잡음 기준선 다시 측정,  m = 설정값(M) 다시 출력

const char VERSION[] = "v3.1";
const float VREF = 5.00;                  // ★ 멀티미터로 잰 우노 5V 핀 전압
const float R1 = 1000000.0;               // ★ 잰 1MΩ 값
const float R2 = 100000.0;                // ★ 잰 100kΩ 값

const int ROW_PIN[4] = {A0, A1, A2, A3};
const int LED_PIN = 13;
const unsigned long SAMPLE_US = 2000;     // 2 ms (행당 500 Hz)
const float TH_ON_V  = 1.0;               // 펄스 시작: 어느 행이든 1.0 V 초과
const float TH_OFF_V = 0.3;               // 펄스 끝: 모든 행 0.3 V 미만이 QUIET_MS 동안
const unsigned long QUIET_MS = 30;
const unsigned long MAX_PULSE_MS = 3000;
const int CLIP_ADC = 1015;                // 이 값 이상이면 클램프에 걸림(약 54 V 이상) → 값이 잘렸음
const unsigned long NONE = 0xFFFFFFFFUL;

float kRow;                // ADC 1칸 → 행 전압(V)
int thOn, thOff;           // 문턱값(ADC 칸)
bool rawMode = true;

// 펄스 상태
bool inPulse = false;
unsigned long pStart, quietSince, prevEnd = 0, pulseCount = 0;
int   peakA[4];
unsigned long tFirst[4], tPeak[4], aboveSamples[4];
float eJ[4], qC[4];
bool  clip[4];

// 잡음·상태
bool calibrating = true;
unsigned long calStart, lastStatus = 0, dropped = 0, lastSample;
long  calSum[4]; unsigned long calN = 0;
int   calMax[4], idleMax[4];
float baseA[4] = {0, 0, 0, 0};   // 잡음 기준선 평균(ADC 칸) — 에너지·전하 계산 때 뺌

void resetCal() {
  calibrating = true; calStart = millis(); calN = 0;
  for (int i = 0; i < 4; i++) { calSum[i] = 0; calMax[i] = 0; }
}

int readPin(int pin) {        // 채널 전환 직후 첫 값은 버림 (분압 저항이 커서 앞 채널 값이 남음)
  analogRead(pin);
  return analogRead(pin);
}

void printV(float v) { Serial.print(','); Serial.print(v, 3); }

void printMeta() {
  Serial.print(F("M,")); Serial.print(VERSION);
  printV(VREF); Serial.print(','); Serial.print((unsigned long)R1); Serial.print(',');
  Serial.print((unsigned long)R2); Serial.print(','); Serial.print(SAMPLE_US);
  printV(TH_ON_V); printV(TH_OFF_V); Serial.println();
}

void setup() {
  Serial.begin(250000);
  pinMode(LED_PIN, OUTPUT);
  kRow  = VREF / 1023.0 * (R1 + R2) / R2;
  thOn  = (int)(TH_ON_V / kRow + 0.5);
  thOff = (int)(TH_OFF_V / kRow + 0.5);
  printMeta();
  for (int i = 0; i < 4; i++) idleMax[i] = 0;
  resetCal();
  lastSample = micros();
}

void endPulse(unsigned long ms) {
  pulseCount++;
  // 첫 접촉 순서 (예: "12" = 1행 다음 2행)
  char order[5]; int n = 0;
  bool used[4] = {false, false, false, false};
  for (int k = 0; k < 4; k++) {
    int best = -1;
    for (int i = 0; i < 4; i++)
      if (!used[i] && tFirst[i] != NONE && (best < 0 || tFirst[i] < tFirst[best])) best = i;
    if (best < 0) break;
    used[best] = true; order[n++] = '1' + best;
  }
  order[n] = '\0';
  unsigned long gap = (prevEnd == 0) ? 0 : (pStart - prevEnd);

  Serial.print(F("P,")); Serial.print(pulseCount); Serial.print(',');
  Serial.print(pStart); Serial.print(','); Serial.print(ms - pStart); Serial.print(',');
  Serial.print(gap); Serial.print(','); Serial.print(n); Serial.print(',');
  Serial.print(n ? order : "0");
  float sampleSec = SAMPLE_US * 1e-6;
  for (int i = 0; i < 4; i++) {
    printV(peakA[i] * kRow);
    Serial.print(','); if (tFirst[i] == NONE) Serial.print(-1); else Serial.print(tFirst[i]);
    Serial.print(','); if (tFirst[i] == NONE) Serial.print(-1); else Serial.print(tPeak[i]);
    Serial.print(','); Serial.print((unsigned long)(aboveSamples[i] * sampleSec * 1000.0 + 0.5));
    Serial.print(','); Serial.print(eJ[i] * 1e6, 4);     // µJ
    Serial.print(','); Serial.print(qC[i] * 1e9, 2);     // nC
    Serial.print(','); Serial.print(clip[i] ? 1 : 0);
  }
  Serial.println();
  prevEnd = ms;
  inPulse = false;
  digitalWrite(LED_PIN, LOW);
}

void loop() {
  if (Serial.available()) {
    char c = Serial.read();
    if (c == 'r') rawMode = !rawMode;
    if (c == 'z') resetCal();
    if (c == 'm') printMeta();
  }

  unsigned long now = micros();
  if (now - lastSample < SAMPLE_US) return;
  unsigned long el = now - lastSample;
  if (el > SAMPLE_US + SAMPLE_US / 2) dropped += el / SAMPLE_US - 1;   // 밀려서 놓친 샘플 수
  float dt = el * 1e-6;
  lastSample = now;
  unsigned long ms = millis();

  int a[4], amax = 0;
  for (int i = 0; i < 4; i++) { a[i] = readPin(ROW_PIN[i]); if (a[i] > amax) amax = a[i]; }

  if (rawMode) {
    Serial.print(F("R,")); Serial.print(ms);
    for (int i = 0; i < 4; i++) { Serial.print(','); Serial.print(a[i]); }
    Serial.println();
  }

  // 시작 2초: 아무도 밟지 않은 상태의 잡음 측정
  if (calibrating) {
    for (int i = 0; i < 4; i++) { calSum[i] += a[i]; if (a[i] > calMax[i]) calMax[i] = a[i]; }
    calN++;
    if (ms - calStart >= 2000) {
      calibrating = false;
      Serial.print(F("B,")); Serial.print(ms);
      for (int i = 0; i < 4; i++) { baseA[i] = calN ? (float)calSum[i] / calN : 0; printV(baseA[i] * kRow); }
      for (int i = 0; i < 4; i++) printV(calMax[i] * kRow);
      Serial.println();
    }
  }

  if (!inPulse && amax > thOn) {
    inPulse = true; pStart = ms; quietSince = 0;
    for (int i = 0; i < 4; i++) {
      peakA[i] = 0; tFirst[i] = NONE; tPeak[i] = 0; aboveSamples[i] = 0;
      eJ[i] = 0; qC[i] = 0; clip[i] = false;
    }
    digitalWrite(LED_PIN, HIGH);
  }

  if (inPulse) {
    for (int i = 0; i < 4; i++) {
      float v = (a[i] - baseA[i]) * kRow;   // 기준선을 뺀 전압
      if (v < 0) v = 0;
      unsigned long rel = ms - pStart;
      if (a[i] > peakA[i]) { peakA[i] = a[i]; tPeak[i] = rel; }
      if (a[i] > thOn) { aboveSamples[i]++; if (tFirst[i] == NONE) tFirst[i] = rel; }
      if (a[i] >= CLIP_ADC) clip[i] = true;
      eJ[i] += v * v / (R1 + R2) * dt;      // 부하에 전달된 에너지  E = ∫V²/R dt
      qC[i] += v / (R1 + R2) * dt;          // 부하로 흐른 전하      Q = ∫V/R dt
    }
    if (amax < thOff) {
      if (quietSince == 0) quietSince = ms;
      else if (ms - quietSince >= QUIET_MS) endPulse(ms);
    } else quietSince = 0;
    if (inPulse && ms - pStart > MAX_PULSE_MS) endPulse(ms);
  } else {
    for (int i = 0; i < 4; i++) if (a[i] > idleMax[i]) idleMax[i] = a[i];
  }

  if (ms - lastStatus >= 10000) {
    lastStatus = ms;
    Serial.print(F("S,")); Serial.print(ms); Serial.print(',');
    Serial.print(pulseCount); Serial.print(','); Serial.print(dropped);
    for (int i = 0; i < 4; i++) { printV(idleMax[i] * kRow); idleMax[i] = 0; }
    Serial.println();
  }
}

def find_port():
    """우노(CH340·Arduino) 포트를 자동으로 찾음. 못 찾으면 목록을 보여 주고 물어봄."""

        return ports[0].device
    print("우노 포트를 자동으로 못 찾았습니다. 연결된 포트:")

        print("  ", p.device, "-", p.description)

def parse_line(line):
    """아두이노 한 줄 → (종류, 값 목록) 또는 (None, 이유)."""
    line = line.strip()
    if not line:
        return None, "empty"
    parts = line.split(",")
    kind = parts[0]
    if kind not in SCHEMA:
        return None, "unknown"
    expect = len(SCHEMA[kind]) - 1          # pc_time 제외
    if kind in ("M", "B"):
        values = parts                       # 종류 글자도 type 열로 저장
    else:
        values = parts[1:]
    if len(values) != expect:
        return None, f"fields {len(values)} != {expect}"
    return kind, values


class Writer:
    def __init__(self, folder):
        os.makedirs(folder, exist_ok=True)
        self.folder = folder
        self.raw = open(os.path.join(folder, "raw_serial.txt"), "w", encoding="utf-8")
        self.err = open(os.path.join(folder, "errors.txt"), "w", encoding="utf-8")
        with open(os.path.join(folder, "columns.txt"), "w", encoding="utf-8") as f:
            f.write(COLUMN_DOC)
        self.files, self.writers = {}, {}
        self.count = {k: 0 for k in SCHEMA}
        self.bad = 0
        self.last_flush = time.time()

    def _writer(self, kind):
        name = FILES[kind]
        if name not in self.files:
            f = open(os.path.join(self.folder, name), "w", newline="", encoding="utf-8-sig")  # 엑셀 한글 안 깨짐
            w = csv.writer(f)
            w.writerow(SCHEMA[kind])
            self.files[name], self.writers[name] = f, w
        return self.writers[name]

    def handle(self, line, pc_time=None):
        pc_time = pc_time or datetime.datetime.now().isoformat(timespec="milliseconds")
        self.raw.write(line.rstrip("\r\n") + "\n")
        kind, values = parse_line(line)
        if kind is None:
            if values not in ("empty",):
                self.bad += 1
                self.err.write(f"{pc_time}\t{values}\t{line.strip()}\n")
            return None
        self._writer(kind).writerow([pc_time] + values)
        self.count[kind] += 1
        if time.time() - self.last_flush > 1.0:
            self.flush()
        return kind, values

    def flush(self):
        for f in list(self.files.values()) + [self.raw, self.err]:
            f.flush()
        self.last_flush = time.time()

    def close(self):
        self.flush()
        for f in list(self.files.values()) + [self.raw, self.err]:
            f.close()

# 압전 타일 분석 v3 — logger.py가 만든 폴더를 읽어 통과(사람) 단위로 묶고 요약
# 실행: python analyze.py piezo_20261205_123000            (추가 패키지 필요 없음)
#       python analyze.py piezo_20261205_123000 --people 812 --count 95
#         --people : 하루 통행 인원(일일 에너지 추정용)
#         --count  : 측정하는 동안 직접 센 통과 인원(센서 정확도 비교용)
#
# 용어
#   펄스  : 아두이노가 잡은 전압 덩어리 1개 (디딜 때 1개, 뗄 때 1개가 보통)
#   통과  : 펄스 사이 간격이 PASS_GAP_MS 이하로 이어진 묶음 ≈ 사람 1명이 타일을 지나감
import sys, csv, os, statistics as st

PASS_GAP_MS = 1000


def read_csv(path):
    if not os.path.exists(path):
        return []
    with open(path, encoding="utf-8-sig", newline="") as f:
        return list(csv.DictReader(f))


def num(x, default=0.0):
    try:
        return float(x)
    except (TypeError, ValueError):
        return default


def main():
    if len(sys.argv) < 2:
        print("사용법: python analyze.py 폴더이름 [--people 하루인원] [--count 직접센인원]")
        return
    folder = sys.argv[1]
    args = sys.argv[2:]
    people = num(args[args.index("--people") + 1]) if "--people" in args else None
    manual = num(args[args.index("--count") + 1]) if "--count" in args else None

    pulses = read_csv(os.path.join(folder, "pulses.csv"))
    status = read_csv(os.path.join(folder, "status.csv"))
    base = read_csv(os.path.join(folder, "baseline.csv"))
    meta = read_csv(os.path.join(folder, "meta.csv"))
    if not pulses:
        print("pulses.csv가 비어 있습니다.")
        return

    # ---- 펄스 정리
    P = []
    for r in pulses:
        p = {"no": int(num(r["pulse_no"])), "t0": num(r["t_start_ms"]), "dur": num(r["dur_ms"]),
             "order": r["order"], "rows": int(num(r["rows_hit"]))}
        p["t1"] = p["t0"] + p["dur"]
        p["E"] = [num(r[f"r{i}_E_uJ"]) for i in range(1, 5)]
        p["Q"] = [num(r[f"r{i}_Q_nC"]) for i in range(1, 5)]
        p["peak"] = [num(r[f"r{i}_peak_V"]) for i in range(1, 5)]
        p["clip"] = any(num(r[f"r{i}_clip"]) > 0 for i in range(1, 5))
        P.append(p)
    P.sort(key=lambda p: p["t0"])

    # ---- 통과 단위로 묶기
    passes, cur = [], [P[0]]
    for p in P[1:]:
        if p["t0"] - cur[-1]["t1"] <= PASS_GAP_MS:
            cur.append(p)
        else:
            passes.append(cur); cur = [p]
    passes.append(cur)

    rows_out = []
    for k, g in enumerate(passes, 1):
        E = sum(sum(p["E"]) for p in g)
        e_odd = sum(sum(p["E"]) for p in g[0::2])     # 1·3·5번째 펄스 (디딤으로 추정)
        e_even = sum(sum(p["E"]) for p in g[1::2])    # 2·4·6번째 펄스 (뗌으로 추정)
        first = g[0]["order"]
        direction = 0
        if len(first) >= 2 and first != "0":
            direction = 1 if first[0] < first[-1] else -1   # +1: 1행→4행 쪽, -1: 반대
        rows_union = sorted({c for p in g for c in p["order"] if c != "0"})
        rows_out.append({
            "pass_no": k, "t_start_ms": int(g[0]["t0"]), "t_end_ms": int(g[-1]["t1"]),
            "n_pulses": len(g), "E_total_uJ": round(E, 4),
            "E_odd_uJ(디딤 추정)": round(e_odd, 4), "E_even_uJ(뗌 추정)": round(e_even, 4),
            "Q_total_nC": round(sum(sum(p["Q"]) for p in g), 2),
            "peak_max_V": round(max(max(p["peak"]) for p in g), 2),
            "rows_touched": "".join(rows_union), "direction": direction,
            "first_order": first, "clipped": int(any(p["clip"] for p in g)),
        })

    with open(os.path.join(folder, "passes.csv"), "w", newline="", encoding="utf-8-sig") as f:
        w = csv.DictWriter(f, fieldnames=list(rows_out[0].keys()))
        w.writeheader(); w.writerows(rows_out)

    # ---- 요약
    Es = [r["E_total_uJ"] for r in rows_out]
    t_first = P[0]["t0"]; t_last = P[-1]["t1"]
    if status:
        t_last = max(t_last, num(status[-1]["t_ms"]))
    dur_s = max((t_last - (num(base[0]["t_ms"]) if base else t_first)) / 1000.0, 1e-9)
    row_E = [sum(p["E"][i] for p in P) for i in range(4)]
    tot_E = sum(row_E)
    dropped = int(num(status[-1]["dropped_samples"])) if status else 0

    lines = []
    add = lines.append
    if meta:
        m = meta[-1]
        add(f"설정: VREF {m['VREF']} V, R1 {m['R1']} Ω, R2 {m['R2']} Ω, 샘플 {m['sample_us']} µs, 문턱 {m['th_on_V']} V")
    if base:
        b = base[-1]
        add("시작 잡음 최대(V): " + ", ".join(b[f"max{i}_V"] for i in range(1, 5)))
    add(f"측정 시간: {dur_s/60:.1f}분, 놓친 샘플: {dropped}개")
    add(f"펄스 {len(P)}개 → 통과 {len(rows_out)}회 (통과당 펄스 평균 {len(P)/len(rows_out):.2f}개)")
    if manual:
        add(f"직접 센 인원 {int(manual)}명 대비 통과 수 오차: {(len(rows_out)-manual)/manual*100:+.1f}%")
    add(f"통과 1회 에너지: 평균 {st.mean(Es):.3f} µJ, 중앙값 {st.median(Es):.3f} µJ, "
        f"최대 {max(Es):.3f} µJ")
    add(f"총 에너지 {tot_E:.3f} µJ, 평균 전력 {tot_E/dur_s:.4f} µW (분압 저항 1.1 MΩ에 전달된 값)")
    add("행별 에너지 비율: " + ", ".join(f"{i+1}행 {row_E[i]/tot_E*100:.0f}%" if tot_E else f"{i+1}행 0%" for i in range(4)))
    dirs = [r["direction"] for r in rows_out]
    add(f"방향: 1행→4행 {dirs.count(1)}회, 4행→1행 {dirs.count(-1)}회, 판단 불가 {dirs.count(0)}회")
    nclip = sum(r["clipped"] for r in rows_out)
    add(f"클램프에 걸려 값이 잘린 통과: {nclip}회" + (" → R2를 47 kΩ로 바꿔 범위를 넓힐 것" if nclip else ""))
    if people:
        day_J = st.mean(Es) * 1e-6 * people
        add(f"하루 {int(people)}명 통과 가정 → 타일 1장 하루 약 {day_J*1000:.3f} mJ ({day_J:.6f} J)")
    text = "\n".join(lines)
    print(text)
    with open(os.path.join(folder, "summary.txt"), "w", encoding="utf-8") as f:
        f.write(text + "\n")
    print("\n저장:", os.path.join(folder, "passes.csv"), ",", os.path.join(folder, "summary.txt"))


if __name__ == "__main__":
    main()

조립 매뉴얼의 값이 실제로 맞는지 하나씩 계산하고 확인했습니다.

검토 항목계산·근거결과
분압비
  • 100 kΩ ÷ (1 MΩ + 100 kΩ) = 1/11
  • 측정점 5 V = 행 55 V
맞음
보호가 충분한가
  • 1 MΩ 직렬: Microchip AVR182 문서 기준 보호 다이오드 전류 1 mA 이하 → 전류로만 보면 약 1,000 V까지. 하지만 1/4 W 저항의 최대 사용 전압(보통 약 250 V)이 먼저 한계 → 실제 한계 약 250 V
  • 1N4148 D1·D2가 측정점을 −0.6~5.6 V로 한 번 더 묶음
  • 압전 펄스는 수십 V 수준 → 여유 큼
안전
1N4148이 측정값을 흐리나
  • 역방향 누설 최대 25 nA (20 V, 25 ℃ 규격)
  • 91 kΩ × 25 nA ≈ 2 mV → ADC 1칸(약 5 mV)보다 작음
무시 가능
음의 전압
  • BR이 전파 정류 → 행 전압은 항상 0 이상
  • 4차시의 음의 반주기 잘림 문제도 사라짐
해결
측정 부하
  • 행 = 디스크 5개 병렬, C ≈ 5 × 15~25 nF = 75~125 nF
  • 걸음 2 Hz에서 Ropt = 1/(2πfC) ≈ 0.6~1.1 MΩ
  • ※ 근사: 디스크마다 BR이 있어 실제로는 눌린 디스크만 부하에 보이고, 한 번 누르는 시간(실측 약 0.1초)은 2 Hz보다 빠름
  • R1 + R2 = 1.1 MΩ로 거의 최적
적절 (C는 추정)
ADC 입력 저항
  • 측정점에서 본 저항 = 1 MΩ ∥ 100 kΩ ≈ 91 kΩ (우노 권장 10 kΩ보다 큼)
  • 채널을 바꾼 직후 값이 앞 채널에 끌릴 수 있음 → 코드가 한 번 버리고 다시 읽음
대책 반영
샘플링·통신 속도
  • analogRead 8회 약 0.9 ms + 원자료 출력 → 2 ms 주기 안에 들어감
  • 원자료 약 30바이트 × 500줄/초 = 15 kB/s, 250000 baud는 약 25 kB/s
  • 펄스 요약 줄(약 230바이트)을 보낼 때 샘플 2~3개가 밀릴 수 있음 → status.csv에 놓친 수로 기록
충분
발걸음 이중 계산
  • 디딜 때·뗄 때 펄스 2개 (v2는 STEP 2번으로 셈)
  • v3: 펄스 사이 1초 이내 → 통과 1회로 묶음
  • 사람이 1초 안에 연달아 지나가면 1회로 합쳐질 수 있음 → 직접 센 인원과 비교해 보정
해결 (한계 기록)
에너지 계산
  • E = Σ V²/(R1+R2) × Δt
  • 모의 신호(8 V에서 시정수 30 ms로 감소): 이론 0.87 µJ, 코드 0.79 µJ — 2 ms 간격으로 재서 첫 순간이 빠지는 만큼 약 10% 작게 나옴
검증
와고 수량
  • 5구: 행 8 + GND 1 = 9 (보유 10)
  • 3구: 행 8 (보유 12)
충분
전선 길이
  • 빨강 10 m = BR 출력선 6 m + 와고 연결 0.4 m + 출력 4 × L
  • L ≤ 약 0.9 m
출력선 짧게, 또는 랜선 추가
BR 전압 손실
  • 다이오드 2개를 지나며 약 1.0~1.4 V 손실 (압전처럼 µA 수준 전류에서 다이오드 1개 약 0.5~0.7 V — 규격서의 1.1 V는 1 A 기준. 1단계 멀티미터 값 1.0~1.4 V와 같음)
  • 약하게 밟으면 손실 비중이 커짐
한계로 기록
여기서 확인하지 못한 것 — 실제 아두이노 보드 업로드와 실제 압전 펄스 모양(코드는 아두이노 기능을 흉내 낸 환경에서 컴파일·실행만 확인), DB107S 다리 배치(1단계에서 몸통 표시로 확인), 아크릴 크기, 고무 범폰 높이, 디스크가 견디는 실제 눌림 양. 이 값들은 단계마다 있는 점검으로 확인합니다.
