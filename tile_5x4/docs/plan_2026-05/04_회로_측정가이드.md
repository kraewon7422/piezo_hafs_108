# Smart Kinetic Floor — 회로 구성 & 측정 가이드

> 실험 직전에 책상 옆에 띄워두고 따라하기 위한 단계별 가이드.
> 이 문서는 "실험 설계 문서"의 부록 역할이며, 측정 프로토콜만 추출한 실전 매뉴얼임.

## 1. 회로 구성

### 1.1 단일 셀 기준 (디스크 1개 + 브릿지 1개)

```
   +-----+   ~     +----------+   +
   |     |---------|          |---+----+
   | 압전 |         |  Bridge  |   |    |
   | 디스크|         | Diode IC |   |    +------+
   |     |---------|          |---+    |      |
   +-----+   ~     +----------+    |    | 캐패  |
                                   |    | 시터  |
                              ─────+    |  C   |
                             (ground)   |      |
                                        +------+
                                          |
                                       (- to GND)
```

- 압전 디스크의 두 선(빨간/검은) → 브릿지의 `~ ~` 표시 단자 (극성 무관)
- 브릿지의 `+` 출력 → 캐패시터 (+) 단자
- 브릿지의 `-` 출력 → 캐패시터 (-) 단자 (전해 콘덴서일 경우 띠 있는 쪽)

### 1.2 8셀 병렬 정류 (실제 실험 구성)

```
[디스크1]─[브릿지1]─┐
[디스크2]─[브릿지2]─┤
[디스크3]─[브릿지3]─┤    공통 +    ┌──[ 캐패시터 0.22 F ]──┐
[디스크4]─[브릿지4]─┼────────────┤                       │
[디스크5]─[브릿지5]─┤            공통 -                   │
[디스크6]─[브릿지6]─┤    ↑                                │
[디스크7]─[브릿지7]─┤    └─ 멀티미터 (+) 빨간 리드 ──┐    │
[디스크8]─[브릿지8]─┘                              (V_c측정)
                                                     │
                  └─ 멀티미터 (-) 검은 리드 ─────────┘    │
                                                          │
                  └─ LED 스위치 (선택) ─────────────────[+/-]
```

핵심:
- 모든 브릿지의 `+` 출력은 한 노드(공통 +)에 묶기
- 모든 브릿지의 `-` 출력은 다른 한 노드(공통 -)에 묶기
- 캐패시터는 이 두 노드 사이에 단 한 개 (병렬)
- 멀티미터 측정은 항상 캐패시터 양단

> **왜 디스크마다 별도 브릿지인가?** 한 디스크에 다른 디스크의 출력이 역으로 들어가 누설이 생기는 것을 막기 위함. 학생 실험에서 가장 큰 함정.

### 1.3 압전 발판 기계 구성 (위에서 본 단면)

```
   ┌─────────────────────────────────────┐  ← 상판 (아크릴 또는 합판)
   │                                     │
   │   ○   ○   ○   ○                     │  ← EVA 폼 (실험 D에서 두께 변경)
   │                                     │
   ├─────────────────────────────────────┤
   │  [디스크1]  [디스크2]  [디스크3]  [디스크4]│  ← 압전 디스크 8개 (격자)
   │  [디스크5]  [디스크6]  [디스크7]  [디스크8]│     베이스에 양면테이프로 고정
   ├─────────────────────────────────────┤
   │                                     │  ← 베이스 (합판, 미끄럼 방지)
   └─────────────────────────────────────┘
```

조립 팁:
- 디스크 사이 간격은 5 cm 이상 (간섭 방지)
- 상판 두께는 3~5 mm (너무 두꺼우면 변형이 디스크에 도달 안 함)
- 디스크 위 직접 발 닿지 않게: 항상 상판 → 폼 → 발 순서

## 2. 멀티미터 설정

1. 다이얼을 **DC V** 위치로
2. 측정 범위: **20 V** 이하 (자동 범위면 무방)
3. 빨간 리드 → 캐패시터 (+) / 검은 리드 → 캐패시터 (-)
4. 가능하면 악어클립으로 고정 (밟을 때 흔들림 방지)
5. 측정 시작 전 **반드시 캐패시터 0 V 사전 방전** (1 kΩ 저항으로 두 단자 짧게 연결, 또는 점퍼선으로 잠시 단락 — 단, 슈퍼캐패시터는 점퍼 직접 단락 시 큰 전류로 스파크 가능, 저항 사용 권장)

## 3. 실험 진행 순서

### 실험 A — 베이스라인 (시간: 약 20분)

1. 캐패시터 0 V 방전 확인
2. 70 N 추(약 7 kg) 또는 본인 체중을 일정 자세로
3. 메트로놈 1 Hz 설정
4. 메트로놈 박자에 맞춰 발판 누름
5. **0보, 10보, 20보, ... 100보** 시점에 일시 정지하고 V_c 측정 → Sheet 1에 입력
6. 측정 후 다시 0 V로 방전, 시행 2~3 반복
7. 시행 3회 데이터 모두 입력 → 자동으로 평균/표준편차/E 계산됨

### 실험 B — 하중별 (시간: 약 30분)

1. 70 N 시행은 실험 A 결과 재사용 가능
2. 30 / 50 / 90 N 추(또는 가능한 가까운 값)로 각각 1 Hz · 100보
3. 하중별 V_c(100보) 기록 → Sheet 2

> 추가 팁: 사람이 발로 밟으면 매번 힘이 다르므로, **가능하면 같은 추를 같은 높이에서 떨어뜨리는 방식**이 데이터 산포가 작음. 학교에 추가 없으면 책 묶음으로 보정.

### 실험 C — 빈도별 (시간: 약 15분)

1. 70 N 고정
2. 메트로놈 0.5 Hz → 100보 → V_c 기록
3. 다시 방전 → 1.0 Hz → 100보 → V_c 기록
4. 다시 방전 → 2.0 Hz → 100보 → V_c 기록
5. Sheet 3 입력

### 실험 D — 완충재 trade-off (시간: 약 40분, ★ 핵심)

각 두께(0/3/6/10 mm)마다:
1. 발판 위에 해당 두께 EVA 폼 올리기
2. 70 N · 1 Hz · 100보 → V_c 기록 (3회 반복)
3. **반발 측정**: 같은 폼 위에서 50 g 골프공을 30 cm 높이에서 떨어뜨려 튄 최대 높이 측정 (3회 반복 평균) → Sheet 4의 G열 (반발높이 h_r)
4. Sheet 4 자동 계산 — K열(가중합) 가장 큰 행이 실용적 최적점

> 골프공 반발 측정 팁: 자를 폼 옆에 세우고 슬로우모션 영상 촬영 → 최고점 프레임에서 자 눈금 읽기. 정확도 ↑

### 실험 E — LED 점등 시연 (시간: 약 15분)

1. 실험 D에서 찾은 **최적 두께** 적용
2. 캐패시터 0 V → 1 Hz로 밟기 시작
3. 멀티미터를 보면서 V_c가 **2.5 V** 도달하는 순간까지 보행 → N_charge 기록
4. **LED 스위치 ON** → 점등 지속 시간 t_LED 측정 (LED가 안 보일 정도로 약해질 때까지)
5. Sheet 5 입력
6. **시행 1번을 동영상 촬영** (PPT 슬라이드 10 시연용 — 발판 → 멀티미터 → LED를 한 컷에)
7. 3회 반복

---

## 4. 데이터 입력 약속

- 측정값을 **현장에서** 시트에 바로 입력 (메모지에 적었다가 옮기면 오타 사고 발생)
- V_c 단위는 **V**, 소수점 2자리까지 (예: 1.42)
- 시행 간 빈 칸 두지 말 것 — 측정 못 했으면 명확히 "결측" 표기
- 한 세션이 끝나면 Sheet 7에 환경 기록 한 줄 추가 (날짜·시각·온도 등)

## 5. 트러블슈팅

| 증상 | 가능한 원인 | 대응 |
|------|------------|------|
| 밟아도 V_c가 거의 안 올라감 | 정류 극성 잘못 / 디스크 단선 | 한 디스크씩 따로 측정해 출력 확인 |
| V_c가 음수 표시 | 멀티미터 리드 반대 | 빨간/검은 리드 교체 |
| V_c가 일정 값에서 멈춤 | 캐패시터 누설/자체 한계 도달 | 정상 — 포화 추세로 기록 |
| 시행 간 V_c 편차 큼 | 밟는 위치/세기 불균일 | 발판 가운데에 발 위치 표시, 추 사용 권장 |
| LED가 점등 안 됨 | V_c가 2 V 미달 / LED 극성 잘못 | V_c 확인 후 LED (+) 길다리 = 캐패시터 (+) |
| 같은 조건 데이터가 매번 다름 | 캐패시터 사전 방전 누락 | 매 시행 전 0 V 확인 의무화 |
| 슈퍼캐패시터에서 약한 거품/소리 | 정격 5.5 V 초과 가능성 | 즉시 회로 분리, 캐패시터 폐기 후 새 것 사용 |

## 6. 안전 규칙 (한 줄씩 기억)

1. 슈퍼캐패시터 정격 5.5 V 절대 초과 금지
2. 압전 디스크는 깨지기 쉬움 — 직접 발 접촉 X
3. 캐패시터는 항상 저항으로 방전 (직접 단락 X)
4. 발판 베이스 미끄럼 방지 (러그 또는 양면테이프 고정)
5. 실험 후 회로 분리 + 캐패시터 방전 확인 후 보관
