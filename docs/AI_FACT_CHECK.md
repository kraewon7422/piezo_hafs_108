## 4. 모델 세대별로 본 경향

- **초기 모델(3–6월)**은 단위·크기 실수(J와 W 혼동, 10⁸배 과대), 지어낸 공식, 칩 기능 과장(LTC3588), 논문 서지 오류가 많았다.
  그대로 시뮬레이터와 발표 자료에 들어간 것이 가장 큰 문제였다.
- **최근 모델(7–11월)**은 인용 자체는 대부분 실재하고 수치도 맞았지만, **맞는 숫자를 잘못된 맥락에 쓰는** 오류
  (특허 발명자, 논문이 다룬 물질, 이미 철회한 R_opt 논리의 재등장, 효율 이중 적용)가 남아 있었다.
- 두 경우 모두, **원 출처를 직접 열어 보는 것**만이 확실한 확인 방법이었다.
