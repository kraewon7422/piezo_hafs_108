> **정오표 (이후 확인)**
> - "Sm³⁺ 이온반경(CN = 12, 1.24 Å)은 표에 없어 외삽값을 썼다" → **틀림.** Shannon(1976) 표에 CN 12 = 1.24 Å가 실려 있다. 계산 결과(t = 0.9843)는 그대로다.
> - Mn 도핑 근거 "Yue 2025" → 이 논문은 Mn을 넣은 **PbTiO₃** 연구이고 반복 하중(피로) 실험은 없다. 효과는 Mn³⁺ 우세 쌍극자에서 가장 컸고, 쌍극자에는 산소 공공이 필요하다(일지의 "상충" 지적을 오히려 뒷받침).
> - "εr를 약 592로 낮춰서 얻은 결과" → 낮은 εr는 특허에서 주로 **Mn 첨가 효과**로 설명된다(릴랙서 PZN이 εr를 낮춘다는 설명은 근거 부족).
> - 특허 US 7,686,974의 발명자는 **S. Priya 단독**(Univ. of Texas System, 2010)이다.
> - 문헌 d·g 순위: APC 850이 7위, Ferroperm Pz24가 8위(당시 표는 두 줄이 뒤바뀜).
> - d₃₁/d₃₃ 비는 소재마다 다르다(PZT 계열 약 −0.4, 변성 PbTiO₃ 계열은 훨씬 작음) → 33 모드 비교는 참고용.
> - 재현성 CV 6.9 %는 모표준편차(ddof = 0) 기준. 표본표준편차면 SD 0.098 V, CV 7.9 %.

## 이번 차시에 얻은 데이터, 관찰 결과 또는 확인한 사실은 무엇인가요?
[시뮬레이터]
- Zr 비율별 전압 피크(코드의 식으로 계산): x = 0.50 → 55.1 V(최대), 0.48과 0.52 → 53.1 V, 0.40과 0.60 → 29.0 V, 0.75 → 22.1 V
- 코드에서 압전 계수가 0.6 + 0.9·exp[−((x − 0.5)/0.08)²]로, x = 0.50에 중심을 두고 입력돼 있었다. 즉 1:1 피크는 시뮬레이션 결과가 아니라 입력한 가정이다. 문헌 실측 최적 조성(MPB)은 Zr:Ti = 52:48이다(Noheda 1999, 2000).

[소재 선택 기준]
- 한 번 누를 때 저장되는 에너지 U = ½(d·g)σ²V, d·g = d²/(ε₀εr) → 준정적 입력에서의 기준은 d₃₃ 하나가 아니라 곱 d·g다(Priya 2010).
- 문헌 11종: ρ(d₃₃, g₃₃) = −0.955(상용 10종만 −0.976) → d가 큰 소재일수록 g가 작다(맞교환).
- ρ(d₃₃, d·g) = +0.518이지만 상용 10종만 보면 +0.830이다. UTA 연구 조성은 d₃₃ 291 pC/N(9위)인데 d·g 16,168 × 10⁻¹⁵ m²/N(1위)로, εr를 약 592로 낮춰서 얻은 결과다.

[제안 조성] (Pb₀.₉₆Sm₀.₀₄)[(Zr₀.₅₂Ti₀.₄₈)₀.₈₈(Zn₁/₃Nb₂/₃)₀.₁₀Mn₀.₀₂]O₃, [001] 배향 조직화
- 전하 합: A자리 +2.04, B자리 +3.96, O −6.00 → 0.00(Mn²⁺ 가정)
- 허용인자 t: 0.9897(PZT 52/48) → 0.9843. 페로브스카이트 안정 구간(0.9 < t < 1) 유지
- 결정 구조(Noheda 2000, P4mm): a = 4.0460 Å, c = 4.1394 Å. B 양이온이 산소면보다 0.299 Å 위에 있어 B–O 결합이 1.848 Å / 2.292 Å로 0.444 Å 비대칭이다 → 자발분극의 기하학적 근원
- 예상 d·g 2~4 × 10⁴ × 10⁻¹⁵ m²/N(두 실측 조성 사이의 내삽, 측정값 아님) → 같은 힘·부피에서 상용 Channel 5400 대비 2.6~5.1배

[4차시 자료 재분석]
- event 14 공진: FFT 3,332 Hz, 파형 봉우리 간격 3,287 Hz → 두 방법이 FFT 칸 간격(104 Hz) 안에서 일치
- 연속 모드: 0.15 V를 넘은 11개 구간 중 뚜렷한 누름은 4회(폭 76–112 ms, 피크 1.109–1.320 V), 평균 1.232 V, CV 6.9 %

## 이번 활동에서 예상과 다르게 나타난 결과, 수행 과정에서 확인한 문제점 또는 현재 방법의 한계가 있었나요?
- 시뮬레이터의 "1:1 최적"은 순환논증이었다. 가정한 곡선이 그대로 출력됐고, Ti 쪽과 Zr 쪽이 완전 대칭(x = 0.40과 0.60이 같은 값)이다. 절대값(55 V, 1 kΩ에서 약 3 W)도 임의 배율(VOLTAGE_SCALE = 18)에서 나온 값이라 실측 개방전압 1.13 V와 비교할 수 없다.
- "d₃₃만으로는 d·g를 예측할 수 없다"고 예상했으나, 상용품끼리는 ρ = +0.83으로 대체로 따라갔다. 11종의 +0.518은 UTA 한 점 때문이었다 → 해석을 "d₃₃을 키우지 않고 εr를 낮추는 길로도 d·g 최상위에 갈 수 있다"로 수정했다.
- 설계 안의 상충: Mn 결함 쌍극자는 산소 공공이 있어야 생기는데, Sm 전하 보상은 공공을 없앤다. 최적 보상비는 실험으로만 정할 수 있다.
- 조성을 직접 만들 수 없다: 하소 850 °C, 소결 1,230 °C, TGG 공정, 수 kV/mm 분극이 필요하다 → 이번 결과는 '제작'이 아니라 '설계 제안'이다. Sm³⁺ 이온반경(CN = 12, 1.24 Å)은 표에 없어 외삽값을 썼다.
- 문헌 d·g는 33 모드 값인데 우리 디스크는 31(굽힘) 모드다 → 소재 사이 상대 비교로만 쓸 수 있다.
- 제안 조성은 무게의 절반 이상이 납이다. 사람이 밟는 바닥용이라면 납이 없고 깨지지 않는 PVDF(d·g ≈ 9,500)가 현실적 대안이다.
- 4차시 자료와 계산을 다시 검토하다 문제 4개를 추가로 발견했다.
  ① event 14 τ = 0.655 ms, Q = 6.9: 피팅 구간이 최대점 뒤 0.38 ms(약 1주기)뿐이었고, 봉우리가 2.1–4.8 ms 동안 0.81–1.13 V로 유지돼 지수 감쇠 모양이 아니었다.
  ② "문헌상 공진 3~4 kHz": 근거를 찾지 못했다. 27 mm 황동 디스크 데이터시트(Murata 7BB-27-4)는 4.6 ± 0.5 kHz로, 측정값이 약 1 kHz 낮다(지지 조건 차이).
  ③ 재현성 CV 75.1 %: 누름 직후의 짧은 흔들림까지 '타격'으로 세고, 80 ms 창이 겹쳐 같은 봉우리를 두 번 셌다. 실제 누름 4회의 CV는 6.9 %다.
  ④ 타일 개수 58개 / 22개: 30 × 30 cm 타일 면적을 0.9 m²로 환산한 값이었다(52.3 ÷ 0.9 = 58, 19.8 ÷ 0.9 = 22). 900 cm² = 0.09 m²이므로 전면 포설은 급식실 581장, 매점 220장이다.
- 4차시에 정한 2.5 V 바이어스(1 MΩ 두 개)는 압전소자에 500 kΩ 부하가 된다. C_p ≈ 20 nF면 RC ≈ 10 ms라서 폭 0.1초의 누름 펄스가 깎인다.

## 이번 차시에 새롭게 결정하거나 변경한 사항은 무엇이며, 그 이유는 무엇인가요?
유지하기로 한 것
: MPB 조성 Zr:Ti = 52:48 — 문헌 실측(Noheda 1999, 2000)에 근거한다. 시뮬레이터의 1:1은 근거로 쓰지 않는다.
: 연속 모드(1 kHz) 측정 — 3.3 kHz 울림은 못 잡지만 0.1초 누름 펄스는 약 100점으로 충분히 기록되므로 재현성 측정에 계속 쓴다.

수정·추가하기로 한 것
: 소재 선택 기준을 d₃₃ → d·g로 변경 — 준정적 입력에서는 공진 증폭이 없고, d와 g가 맞교환하기 때문이다.
: 조성 제안 채택 — 레버 5개(MPB 유지 / Zn·Nb 10 % / Sm 4 % / Mn 2 % / [001] 조직화). 목표는 d를 지키면서 εr를 낮추는 것이다.
: 전하 보상은 완전 보상(Sm 0.04)을 기준선으로 두고, 최적 보상비와 Mn 원자가(XPS/EPR로 확인)는 실험 변수로 남긴다.
: 4차시 기록 정정 — τ·Q는 "이 데이터로 정하지 않음", 공진 비교값은 데이터시트 값, 재현성은 누름 4회 CV 6.9 %(GitHub README §2-6에 정정 전후를 표로 남김). 타일 개수는 전면 포설 급식실 581장 / 매점 220장으로 고치고, 실제로 몇 %를 깔지는 동선을 보고 따로 정한다.
: 낙하추 지그의 목적 변경 — "CV 75 % 낮추기"에서 "가한 힘을 알고 고정하기"로. 상용 소자 비교에 같은 힘이 필요하기 때문이다.
: 2.5 V 바이어스 재설계 — 분압 저항을 키워 RC를 펄스 폭보다 충분히 길게 하거나, OP앰프 버퍼를 넣는다.
: 다음 차시 계획에 추가 — 상용 소자 3종의 d·g 비교. 제안의 근거가 된 명제를 우리 데이터로 검증하되, 결과를 "어긋난다"로 미리 정하지 않는다.

제외하기로 한 것
: 시뮬레이터의 1:1 피크를 조성 근거로 쓰는 것 — 입력한 가정이 그대로 나온 값이다.
: "d₃₃만으로 d·g를 예측할 수 없다"는 표현 — 상용품 기준 ρ = +0.83과 맞지 않는다.
: event 14의 τ·Q 값, "문헌상 3~4 kHz" 문구, "세기가 8배 차이" 문구.

## 다음 차시가 시작되면 가장 먼저 수행할 일은 무엇인가요?
LCR 미터로 27 mm 디스크의 C_p를 측정한다(없으면 알고 있는 저항과의 RC 시정수로 역산). 같은 방법으로 상용 소자 3종의 C_p도 재 둔다. C_p가 정해져야 ① 4차시 유도 물리량 표의 실제 에너지 값이 확정되고 ② 2.5 V 바이어스 저항값(RC ≫ 0.1 s)을 고를 수 있으며 ③ 상용 소자 d·g 비교에서 g를 역산할 수 있다.
